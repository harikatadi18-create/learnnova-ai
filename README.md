# LearnNova AI

AI-powered academic learning platform.

> Learn smarter. Grow faster.

## 🚀 About

LearnNova AI is an AI-powered academic platform designed to help students
learn, organize, practice, track their progress, and grow their skills.

## 🎯 Vision

To become a trusted AI learning companion for students.

## 🧠 Core Features

- AI Tutor
- PDF Learning
- AI Notes
- Quiz Generator
- Personalized Study Planner
- Learning Analytics
- Progress Dashboard
- Placement Preparation
